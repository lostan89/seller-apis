# Описание скрипта Seller.py

При запуске скрипта скачивается актуальное наличие часов с сайта timeworld.ru.
Формируется прайс-лист для загрузки на маркетплейс OZON.
Обновляются остатки и и цены товара на OZON

## Что делает

1. Запрашивает список товаров продавца (`get_offer_ids`).
2. Загружает актуальные остатки из источника (`download_stock`).
3. Формирует данные об остатках (`create_stocks`) и отправляет их порциями по 100 штук (`update_stocks`).
4. Формирует данные о ценах (`create_prices`) и отправляет их порциями по 900 штук (`update_price`).
5. Обрабатывает сетевые ошибки: таймаут, обрыв соединения, прочие исключения.

# Описание скрипта Market.py

Скрипт обновляет остатки товаров и цены на Яндекс Маркете для двух моделей отгрузки: 
**FBS** (отправляет маркетплейс) и **DBS** (отправляет продавец).

## Что делает

1. Загружает актуальные остатки из источника (функция `download_stock`).
2. Для каждой модели (FBS и DBS):
   - Запрашивает список товаров продавца через API Маркета (`get_offer_ids`).
   - Формирует данные об остатках (`create_stocks`) — товары, которых нет в выгрузке, получают нулевой остаток.
   - Отправляет остатки порциями по 2000 штук (`update_stocks`).
   - Обновляет цены (`upload_prices`).
3. Обрабатывает сетевые ошибки: таймаут, обрыв соединения, прочие исключения.
